# Verde Slaný — pracovní web

Veřejná prezentace obou projektů včetně výběru bytů, 3D prohlídek a filmu.

Ceny a dostupnost: publikovaný přehled z 9. 11. 2026. Poptávky připravují e-mail ve vlastní poště návštěvníka. [Administrace](https://frantisekdron.github.io/verde-slany/admin/) je na GitHub Pages, přihlášení a soukromá data zajišťuje Cloudflare. [Testovací prostředí](https://frantisekdron.github.io/verde-slany/admin/?demo=1) má oddělenou databázi. Soukromé kontakty, hesla a zálohy nejsou v repozitáři. Aktualizace obsahu z administrace se na veřejný web zatím vydávají samostatným nasazením. Postup je v [admin-platform/README.md](admin-platform/README.md).

3D model Verde II (SO 05) a samostatné prohlídky obou bytů jsou propojené s výběrem podlaží.

Média a jejich zdroje jsou v souboru `media-selection.json`.
