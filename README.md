# Verde Slaný — pracovní web

Veřejná prezentace obou projektů včetně výběru bytů, 3D prohlídek a filmu.

Ceny a dostupnost: publikovaný přehled z 9. 11. 2026. Poptávky připravují e-mail ve vlastní poště návštěvníka. Privátní administrace a CRM nejsou součástí tohoto veřejného repozitáře. Aktualizace administrace se sem zatím automaticky nepřenášejí.

3D areál: schválený finální model a podklady byly převzaty 10. 11. 2026 ze zdrojů předání. Kontrolní součty jsou v `areal/model-version.json`. Samostatný model ve výběru bytů zůstal bitově zachován.

Média: finální film F2 v14 (103,68 s), odpovídající české titulky, schválené vizualizace a retušované fotografie. Původ a kontrolní součty: `media-selection.json`. Obrázky mají responzivní WebP náhledy; dialog používá plnou velikost.
